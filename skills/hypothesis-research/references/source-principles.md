# Source principles and deliberate adaptations

Read both supplied two-page prompts in full on 2026-09-27:

- [Jacobian Conjecture Prompt](https://aaronlou.com/jacobian_counterexample_prompt.pdf).
- [OpenAI Cycle Double Cover prompt](https://cdn.openai.com/pdf/04d1d1e4-bc75-476a-97cf-49055cd98d31/cdc_prompt.pdf).

These are workflow inspiration, not live task instructions or evidence that a
mathematical claim has been proved. Their common principles motivate diverse
approach families, early independence, a registry, concrete deliverables,
adversarial scrutiny, and repeated synthesis. In particular, a missing lemma
as hard as the original task must remain visible rather than count as a solution.

This skill adds an empirical layer for computational research: falsifiable
predictions, tiny-instance oracles, exact witness checking, reusable fast kernels,
matched-resource experiments, persistent evidence and interruption-safe handoffs.
Those implementation choices are adaptations, not quotations from the prompts.

Deliberately not inherited:

- A fixed agent count or tool name; use only available, authorized resources.
- A minimum eight-hour run or a requirement to continue until success.
- Assuming that a proof exists, or preferring proof over counterexample by default.
- Prohibiting searches for existing solutions; literature and novelty checks are
  part of this user's workflow unless a later task explicitly restricts them.
- Rejecting useful partial results: record them accurately, without calling them
  complete proofs or final resolutions.

When a project uses another evaluation skill, retain the actual user-authorized
evaluation contract. This skill neither invents official scores nor requires
replacing a working independent checker with a particular platform.
