# Alternative intrinsic quotient portfolio

## H-QP-001

The published 768-vertex adjacency has a discovered partition into 192
four-vertex fibers, but block independence depends on the partition.  This
screen therefore changed the partition itself rather than editing finite
edges or perturbing the existing 192-class means.

The adjacency supplies two intrinsic relations between old fibers.  Its 96
degree-two blocks form a perfect matching and each is two disjoint `K2,2`s;
their red-aligned and blue-aligned halves give two new partitions into 192
cells of size four.  Its degree-three defect relation is 11-regular; three
deterministically distinct perfect matchings, together with the three pairings
of each missing four-edge matching, give three more equal-size partitions.
Controls are the original four-sheet partition, a seeded random `2+2`
regrouping inside each degree-two matched pair, and a global seeded random
size-four partition.

Every block probability starts at its exact ordered edge average.  Every
partition then receives the same all-18,528-coordinate projected-Adam search,
with each dyadic trial selected by an exact C++128 partition count.  A tiny
four-class literal ordered enumeration and exact reproduction of the frozen
192 parent gate the evaluator; every retained portfolio member receives an
independent direct ordered-index C++128 recount.

Prediction: an adjacency-derived regrouping enters a quotient-graphon basin
below the identically optimized original partition and both matched random
controls.  Failure is limited to these partitions and the bounded optimizer.

## Results

Run001 used steps `0.02,0.05,0.1`.  Seven of eight members stalled at their
initial average, so it is retained as an optimizer-resolution failure rather
than the decisive comparison.  Run002 preregistered a refined common step
bank `0.0005,0.001,0.002,0.005,0.01,0.02` and finished all eight members in
60.44 seconds.

The original four-sheet control remained best at
`0.030139339238034094`.  The alternative results were:

| Partition | Exact optimized density |
|---|---:|
| degree-two red `K2,2` | 0.03136268746080024 |
| degree-two blue `K2,2` | 0.031377885638900316 |
| defect matching 0 | 0.0313660204222208 |
| defect matching 1 | 0.031366709647219056 |
| defect matching 2 | 0.03136604432508307 |
| random local `2+2` | 0.03137058002897802 |
| random global size four | 0.03125757022587416 |

The red `K2,2` and defect partitions modestly beat the matched local-random
control, so the intrinsic relations carry detectable structure.  But every
alternative is more than `0.0011` above the retained two-parameter parent
`0.03013897728988013`; even the identically optimized original control stops
`3.62e-7` above that parent.  The preregistered prediction is therefore
falsified for this bank, and none of these candidates warrants Lean
promotion.  Retire these particular size-four regroupings.  The experiment
does not address other cell sizes, true graph automorphism orbits, partitions
not generated by the two observed fiber relations, or stronger optimizers.
